# Release Notes (1.4.x)

## 1.4.0

Release notes for Apache Pekko Persistence JDBC 1.4.0. See [GitHub Milestone](https://github.com/apache/pekko-persistence-jdbc/milestone/10?closed=1) for a fuller list of changes.

### Main changes

* The `pekko-persistence-jdbc-migrator` module is now published. It migrates data from the legacy pre-5.0.0 Akka Persistence JDBC schema to the current schema, see @ref[Migrating from the legacy schema](../migration.md#migrating-from-the-legacy-schema). Support for the legacy schema is removed in 2.0.0.
